# Farm Profile 3D — Phase 2 handoff

The production Farm Profile uses `ProceduralField3D` and its new shared `AgriculturalTerrain`; the isolated Vite development page `/parcel-preview.html` uses the same terrain and camera fit. The existing step decorations remain unchanged for compatibility. They are not new Phase 3 behavior.

GeoJSON Polygon and MultiPolygon rings, including holes, are projected approximately to local metres using latitude-adjusted longitude, centered on bounds, scaled uniformly, and extruded without bevel. No payload or geometry is mutated. This local equirectangular approximation is intended for small fields, not dateline-crossing or polar polygons; validate degenerate/self-intersecting geometry upstream. Extrusion depth is illustrative. Camera fit uses projected coordinates, not field stretching.

Ground103 color/NormalGL/roughness forms the top; Ground102 color/NormalGL/roughness the sides. Color maps use sRGB; data maps use no color space. Both repeat and use anisotropy 4. The top shader adds subtle illustrative furrows; no crop identification is inferred. Sides are darkened Ground102, not verified geology; no physically stratified cutaway exists. Texture scale is normalized to the footprint, not to physical meters, so results need review for parcels with very different real sizes. Maps are loaded through drei and cloned per terrain; clones and extruded geometry are disposed on unmount.

`npm run build` passed (large-chunk warning); `npm test` passed 45 tests. The dev preview was viewed with rectangular, irregular and narrow polygons in the browser. Browser console inspection reported no errors or warnings at the time. No saved browser screenshots or mobile/performance profiling were obtained. The visible result remains a largely bare slab and does not meet the requested cinematic reference quality. The scene still needs richer agricultural detail, improved soil sides, full responsive testing and production workflow verification before Phase 2 can be considered complete. Do not add fake detected vegetation or alter the true footprint.
